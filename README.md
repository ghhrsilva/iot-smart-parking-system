# IoT Smart Parking System

An ESP32-based IoT parking automation system developed for the SLIoT competition.

The system detects vehicles using ultrasonic sensors, automatically controls a servo-powered gate, and publishes environmental data (temperature and humidity) to a cloud MQTT broker.

---

## Hardware

- ESP32 WiFi development board
- Ultrasonic sensors (vehicle detection)
- Servo motor (gate control)
- DHT11 temperature and humidity sensor
- I2C LCD display
